# Cuddle-seed decode campaign (end-to-end confirmation)

**Date:** 2026-07-19 · **What:** feed the cuddle-generated seeds to the **real Amaru CBOR decoders**
(`amaru_kernel::from_cbor_no_leftovers::<T>`) and classify accept/reject. Confirms the shallow cuddle
integration works end-to-end and shows exactly where the structural-only ceiling bites.

## Setup

- Shims built on the box from `dwarf/targets/amaru` (path-deps `codebases/amaru`, `codebases/pallas`),
  release, x86_64-linux: `amaru-cbor-decode-{block-header,block,tx-body}`.
- Inputs: the 16 valid cuddle seeds per shape (Conway CDDL, `cuddle gen --no-twiddle -f binary`).
- Each seed piped to the shim; exit 0 + `OK` = accepted (decodes + no leftover bytes), else rejected.

## Result

| shape | accepted | rejected | note |
|---|---|---|---|
| **block-header** | **16 / 16** | 0 | real Amaru decoder accepts every cuddle seed ✅ |
| block | 0 / 16 | 16 | `decode error: invalid address: MissingHeader` |
| tx-body | 0 / 16 | 16 | `decode error: invalid address: InvalidAddressLength(0)` |

## What it means (honest)

- **The pipeline works.** cuddle seeds flow into the real decoders and are classified. For
  `block-header` — which embeds no address — **all 16 cuddle seeds are accepted**, proving the
  integration end-to-end.
- **`block` and `tx-body` are rejected on ADDRESS validation, not CBOR.** Root cause: the Cardano
  CDDL defines `address = bytes` (opaque — the real header-byte / credential structure is only a
  *prose comment* at conway.cddl:148, not machine-checkable CDDL). cuddle faithfully generates random
  bytes for the address field; those decode as CBOR but fail Amaru's stricter in-decoder address
  parser. This is a concrete instance of the documented **structural-vs-semantic ceiling**: the CDDL
  under-specifies addresses, so CDDL-derived seeds satisfy the shape but not the implementation's
  sub-byte address invariants.

## Consequences / follow-ups

- **block-header** cuddle seeds are directly usable as-is (accepted → reach deep decode paths).
- For **block / tx-body**, cuddle seeds currently exercise the *address-reject* path. To reach deep
  decode, post-process the generated CBOR to inject **structurally-valid address bytes** (a correct
  header nibble + credential of the right length) into the tx-output address fields — a small
  transform on cuddle output. Tracked with the mini-protocol work (task #41 / deep integration).
- Useful signal for the Amaru team: a spot where the official CDDL is looser than the implementation
  (addresses), i.e. where CDDL-only test generation needs a semantic assist.
